# Midea-cloud python lib

[![Python build](https://github.com/midea-lan/midea-cloud/actions/workflows/python-build.yml/badge.svg)](https://github.com/midea-lan/midea-cloud/actions/workflows/python-build.yml)
[![codecov](https://codecov.io/github/midea-lan/midea-cloud/graph/badge.svg)](https://codecov.io/github/midea-lan/midea-cloud)

Control your Midea M-Smart appliances via cloud.

## Credits

The cloud client was moved here from
[midea_auto_cloud](https://github.com/sususweet/midea_auto_cloud), the Home
Assistant custom integration by [@sususweet](https://github.com/sususweet).
It was ported to an async library so the Home Assistant core `midea`
integration can use it. Many thanks to sususweet for the original work.
